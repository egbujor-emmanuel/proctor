The problem

A score says nothing about tomorrow.

Benchmarks leak

Public test sets end up in training data, so a high score can mean the model memorised the test.

Models get swapped

An agent certified today can switch to a cheaper model behind the same endpoint. A buyer on an agent marketplace has no way to notice.

How it works

Seal, sit, certify, re-test.

01 · Seal

The exam is an OutLayer secret, readable only by one runner build (by SHA-256) and only via the registry. Only its hash is on chain.

02 · Sit

Anyone pays for a sitting. OutLayer runs the runner in Intel TDX; it asks a NEAR AI model, or an agent's own endpoint, each question and grades by fixed rules.

03 · Certify

The registry writes a certificate only from OutLayer's callback, after re-checking exam, candidate, sitting and arithmetic.

04 · Re-test

Anyone may re-test hourly. One fail suspends, two in a row revoke, a pass restores. Outages never fail a model.

Trust model

What you don't have to take on faith.

  • The exam is never published. Only its commitment is on chain.
  • The score isn't self-reported. Certificates come only from OutLayer's callback.
  • A model's answers came from NEAR AI, signed in its TEE or NEAR AI's TEE gateway. For an agent, the ids prove real completions only.
  • The grader can't change without notice. New runner builds wait out a 24-hour timelock (code upgrades don't yet).
  • Outages don't fail a model. Only an agent silent for three re-tests in a row takes a strike.
